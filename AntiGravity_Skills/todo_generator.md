# TODO Generator

When asked to create a new task in `TODO.md`, you MUST use the following template so no external context is required to complete it.

```markdown
- **Task Title** Choose `Gemini Flash`, `Low`, `High`, 'Sonnet', or 'Opus' (use `Sonnet` or `Opus` only for very difficult issues). Sort tasks in each section by model (Flash first)
  - **Goal**: One sentence describing the desired outcome.
  - **Files to read**: List every file the implementer must read first.
  - **Files to modify/create**: List files that will change.
  - **Steps**:
    1. First concrete step…
    2. Second step…
  - **Acceptance**: How to verify the task is done.
```
